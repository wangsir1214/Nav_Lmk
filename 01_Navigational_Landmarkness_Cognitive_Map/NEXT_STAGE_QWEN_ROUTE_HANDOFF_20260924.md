# Pilot 0 后续：候选区域与连续路径并行试验

日期：2026-09-24。状态：下一轮执行方案，所列样本数与距离带是预注册的试验起点，不是已验证的经验结论。

## 科学问题与当前证据

研究问题是：哪些街景线索在导航中有用，能否作为地点、方向与路线记忆的锚点？当前冻结开发题库的 44 query、168 reference、82P/6160N/1150I 和 G/14+urban VLAD 基线只测完整图的局部地点对应。Recall@1 为 42/44；P 全部同路且约 9.7–32.5 m，N 全部异路且约 88.6–1275.7 m。它不能单独验证具体线索、同路细粒度定位、道路选择或认知地图。

下一轮同时推进两条线：A 线检验候选区域是否贡献地点对应；B 线尽快建立连续路径/路口决策可行性。A 线不要求先完成新的困难负例，B 线不要求先完成 44 图全部候选干预。两条线的正式结论须在各自真值、对照和分组分析完成后给出。

## A 线：单图候选与区域贡献

1. **模型与试运行。**服务器检查显存/磁盘/网络后，从官方仓库下载 `Qwen/Qwen2.5-VL-7B-Instruct` 至 `/home/nas/wangyq/model_weights/Qwen/Qwen2.5-VL-7B-Instruct`，固定仓库 commit、处理器与推理版本；该型号是本轮可执行默认选择，之前讨论的 Qwen3.5-9B 仍是未核验的备选。先用 2 图做 JSON/坐标 smoke，再预先按规则选 12 个 query view：含 2 个失败、4 个低 margin 答对、4 个高 margin 答对、2 个中间层随机；尽量一 pano 一图、覆盖六个道路组，冲突时记录实际分布。这里是 12 张 query 图，不是 12 对 P/N。
2. **候选提议。**逐张输入原始 640x640 单视图，不给 GPS、panoid、reference、P/N/I、VLAD 分数或答案。每图最多 3 个可见候选，包含 `view_id`、`bbox_xyxy_640`、`type`（object/structural/text/scene）、`description`、`hypothesized_role`、`visibility`、`model_revision`、`prompt_hash`。允许 `no_clear_candidate`。保存原始输出、解析失败和完整提示。模型内部图像处理尺寸单独记录，不能误称为 DINO 的 448 输入。
3. **人工审核。**审核 12 图的全部候选，约 0–36 框。每框判 `ACCEPT/EDIT/REJECT/UNCERTAIN`，检查真实可见、所述实体/结构与框一致、框紧贴目标且不过度带入道路/天空/其他建筑、没有重复、没有越界、是否为临时遮挡物、在邻近观察能否指认同一线索。修改框须保存模型原框与人审终框；`UNCERTAIN` 不进入主干预。审核的是视觉事实，不按检索分数选框，也不因显著就标成已验证地标。12 图试运行稳定后冻结提示与规则，扩到全部 44 query。
4. **坐标与 patch。**DINO 图为同画布 640→448 缩放，比例 0.7；ViT-G/14 的 448/14=32，故每个 patch 约对应原图 20x20 像素。按确定的像素边界、patch 覆盖比例（首版 >=50%）和 row-major `index=32*row+col` 将人审框映射为 patch 集合。预览 overlay 并单元测试四角、细小框、边界框。小于 4 个有效 patch 的框保留在候选清单，但不做首版 descriptor 干预；这不是对地标价值的否定。
5. **匹配对照。**每框在同图中以固定 seed=42 搜索最多 3 个不相交对照，复制同一 patch 形状与 patch 数，中心纵向位置相差不超过 3 个 patch，避开已审核候选/明显遮挡和边缘裁断；优先匹配粗略图像内容和边缘密度，不能以模型成绩挑对照。记录每一项偏差。找不到合格对照则标 `no_valid_control`，不强凑。
6. **descriptor 干预。**优先核验并复用已有 212 个 `1024x1536 float32 row_major` patch 文件，路径见 NAS 的 `feature_index.csv`；核验 212 路径/哈希/形状，并抽样重聚合复现 full VLAD。固定 reference、P/N/I、urban 32-center 词典和评分器，只改变 query patch 行集合。分别重新聚合 `full`、`candidate_drop`、`candidate_keep`、`control_drop`、`control_keep`，执行原有簇内及全局归一化。drop 要删除行，不能把最终 49152 维 VLAD 向量置零或相减；keep 使用的 patch 仍含整图上下文，不等同于只看局部像素。
7. **报告。**对全部固定 N 重新打分，逐 query 保存最高 P 相似度、最高 N 相似度、margin、最佳 P 排名、Top1、实际 patch 数与各控制区。主要比较 `M_full-M_candidate_drop` 与 `mean(M_control_drop)-M_candidate_drop`，同时查看 keep 的候选-对照差。报告零效应、反向效应和按 pano/道路组汇总；12 图只作流程检查，正式描述性结果用全部可审的 44 图。随后在少量预定案例上以同样候选/对照进行像素遮挡并完整重跑 DINO，检验 descriptor 结果对输入级干预是否稳健。

## 独立的同路困难负例题库

原 44 query 仍足够启动 A 线，不必作废。若要说“能在同一条道路上定位到正确路口/路段”，需另立版本：先从相同道路、相似朝向的 reference 搜索沿路 50–100 m 与 100–200 m 两层候选 N；`>50 m` 是本轮候选起点，不是普适的正负分界，必须与各 query 的 P 容差、路口/决策区和实际图像重叠共同核对。约 30–50 m 的边界先列 I；不把旧 I 批量改 N。每 query 争取至少 2 个经审查的同路 N，若六道路现有图库不够，扩图库并新建 manifest。重点检验是否分得清相邻决策区，而不是追求任意 5 m 的拍摄点精度。先产出分布和审核板，经人工确认后冻结新题库，再运行 full 和候选干预；旧版指标始终单独报告。

## B 线：尽快做连续路径实验

1. **准备可行性材料。**复用 `_audit_outputs/candidate_route_steps.csv`、路线图板和历史路网审计。先做 4 条左右左/右路线的端到端 smoke，再争取 6–9 条人工确认路线、左右直行尽量平衡。对同月/相近月份连续性、相邻点重复、路口候选出口合法性、施工眩光/季相和动作标签做快速检查。当前 `main_11` 不能作为多出口选择；`main_09/10/12` 等混淆需修复、分层或替换。若无法找到合格直行，不补虚假样本，按实际覆盖报告。历史机审 `provisional_maneuver` 不能当 gold。
2. **定义非泄漏任务。**先做“看过路线后在路口续行”而非无目标的图片猜转向。学习阶段给按行进顺序的短连续街景（路口前、路口、正确出口后的视图）；测试阶段给同路线的未在学习中出现的临近观察、当前路口和至少 2 个合法非回头出口选项，选哪条边继续已学习路线。不能在测试提示中直接写正确的 left/right/forward，也不能用 panoid/文件名透露答案。训练/测试视图或观测点重复须检测并报告。若只能复用相同决策图，标为 smoke 而非正式泛化评估。
3. **视图与朝向。**正式方向任务从 ERP 按来向 bearing 重投影四个 FOV=90° 视图；固定 `view_0..3` 的绝对中心始终为 `(heading_from_api+90*i)%360`，不能直接称其为前后左右。路线、heading、ERP、投影参数和选项边 bearing 单独留在评分端；模型端只给设计条件允许的信息。
4. **输入条件。**主条件为按顺序的路线图像、当前路口四视图和匿名候选出口图像/选项 ID，不给绝对经纬度、地名或原始 panoid；候选边方位若给所有条件都给。对照条件为打乱学习顺序或只给当前图；之后比较候选线索列表、候选遮挡与匹配遮挡。GPS/绝对坐标仅做附加的地图辅助上界，不能混进视觉导航主结论。视觉-路线条件测路线记忆与可见线索使用；加坐标条件混入地理先验/拓扑定位能力。
5. **输出与评分。**输出限定 `chosen_edge_id`、`maneuver`、`evidence_view_id`、候选线索/方位、理由和 `uncertain`；置信数值仅作自报，不当校准概率。评分包括合法边选择准确率、与随机/只看当前图/打乱顺序的差、证据是否真可见且与所选边相关，以及遮挡候选相对匹配控制后正确率/选择稳定性的变化。按路线/决策区汇总，不把同路线多个问法当独立样本。少量路线结果只叫 feasibility，不作显著性或城市泛化结论。
