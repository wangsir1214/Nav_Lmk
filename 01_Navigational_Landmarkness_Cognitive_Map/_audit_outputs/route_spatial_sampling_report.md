# Paris 路线空间采样审计 v2

## 坐标、单位与限制

主结果读取附件 `Paris_Points_heading_3059.csv` 中按 pano ID 保存的 `lng_from_api/lat_from_api`，它们是 Tile API 返回的全景位置，不是吸附路中线后的点。
从 WGS84 EPSG:4326 转为法国 Lambert-93 **EPSG:2154**，`always_xy=True`，在米制平面计算两拍摄位置直线距离；以 WGS84 椭球测地线独立交叉核对。
工具为 pyproj 3.7.2/PROJ，版本、变换、输入哈希和命令保存在 provenance JSON。

源中还保留历史 `lon/lat`，已与原始点表和贴路前图 pos 逐点对上；两套未吸附坐标不完全相同，本批最大差约 9.01m。
不能把任何一套看成实测厘米级真值，无法仅从差异判定哪次 API 校正更准。
因此 distances CSV 同时给出历史原始坐标、吸附图坐标的距离，summary 同时给出历史坐标 5m 有效数。
主结果不是图 edge weight，也不是完整人行/驾车路线长度。`route_distance_m` 是相邻观测位置直线距离之和，不保证遵循车道、绕行、道路曲线。
小于1m/2m等阈值仅用于近重复风险筛查，不代表测量精度。

## 可复算规则

- 阈值均严格比较：`<1m`、`<2m`、`<5m`、`>20m`；边界本身不计入。
- 标准差为总体标准差（ddof=0）；`spacing_cv = std / mean`，不以无效除法填零。
- `effective_distinct_observation_count`：保留 step 0，按序扫描，当前点与最近一次保留点距离 >=5m 才计一个新观察。只计算，不删除或修改原数据。不是沿线累加距离，也不合并非连续重访。
- 同时报出 2m、10m 的敏感性，以及 5m 保留序号。这是**空间分离代理指标**，不证明视觉独立；同地点不同朝向/时间可很不相似，但不能冒充新的空间位置。
- 该贪心代理可能略过重要 decision step，不能直接拿这些保留序号生成正式刺激。正式取样必须保留经确认的决策点/入口/出口，处理与其冲突的邻近点。

### 空间质量 0–4（按顺序判定）

0：5m 有效观察 <=2。
1：否则有效观察 <=4，或 <2m 相邻对 >=3。
2：否则有效观察 <=6，或存在 <2m、>20m 相邻对，或 CV>0.8。
3：否则有效观察不足8，或存在 <5m 相邻对，或 CV>0.5。
4：其余。0–2 标记 YES，3 为 OPTIONAL，4 为 NO；这是重采样筛查规则，不是图像质量量表。
20m 是提示检查的阈值，不是道路不连续的证明；分数不能单独决定科学淘汰。

## 主要发现

105 个相邻对：8 个 <1m、16 个 <2m、37 个 <5m、1 个 >20m。阈值计数嵌套，不能相加。
5m 代理下 120 个 step 合计约 84 个有效观察，单路线 4–8 个；14/15 不足8个。
只有 main_03 的 8 个点均达到 5m 分离，但它有跨年点和一次20.77m间隔，所以“空间不同”不等于“可直接实验”。
arc_control_02 为7个；main_01/main_05仅4个。main_04 有三对不足2m，其中最短约0.094m，是优先处理的近重复。
main_07/08/10/11、arc_control_01 也出现 <1m 相邻对。main_02、arc_control_03 没有 <2m 对，但仍存在较密采样。

建议 P1B 不再以固定8个pano保证路线长度，而是按物理间距、经确认的路口阶段、视觉变化联合选择观察，并控制学习总时长/暴露量。
建议先尝试5–10m观测间距而非硬性规则，在路口保留必要近点；不能只按视觉变化挑图，否则可能主动挑入天气/施工变化。
距离问题本身可用现有观察去冗余或扩展同路段处理，不需要重新采集所有图片。
没有路线已被证明只改点间距就完全合格：还要联合时间、出路语义和视觉混淆检查。
main_04 的低显著度、main_01/05/06/08 的结构场景角色仍值得保留；main_11 的单出口问题不能靠间距处理解决。
