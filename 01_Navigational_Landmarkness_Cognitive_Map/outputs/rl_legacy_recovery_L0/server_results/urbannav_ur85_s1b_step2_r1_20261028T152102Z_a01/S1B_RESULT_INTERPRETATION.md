# 视觉依赖解释边界

- Full: 24/24成功，0超时。
- NoImage: 2/24成功，22超时。
- ShuffledImage: 1/24成功，23超时。

Full与对照按episode_id配对，任务/seed/Goal不变，真实策略闭环各自演化。若NoImage下降，说明移除正常视觉影响当前任务表现，但全零输入可能分布外；若ShuffledImage下降，支持正确位置匹配的街景在当前任务集具有效用，也可能反映破坏连续时空一致性。近距离donor按既定映射保留，不能据结果重选。

24题每条件一次、探索性任务、100m成功边界，不支持普遍机制或跨城市外推；不证明特定地标、区域贡献、认知地图，也不等于历史随机多目标成功率。没有计算不兼容动作空间下的SPL。成功所需动作只对成功题定义；timeout的1000为删失/受限值。

下一步建议仅供人工设计：同状态视觉输入与动作概率/双GRU响应对照、长停留或局部循环起点诊断，以及视觉匹配和时序连续性贡献的进一步区分。均需单独授权，未在本轮运行。
