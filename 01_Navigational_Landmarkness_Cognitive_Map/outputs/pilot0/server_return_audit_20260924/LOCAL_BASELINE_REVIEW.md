## 研究解释与下一阶段

当前完整图表示对这份开发题库具有较强判别能力。高Recall不要求人为降低成绩，也不意味着题库作废。后续应以连续的margin变化和匹配区域对照为核心，同时报告Recall和排名变化。

任务边界必须保留：全部82P来自同一道路段、距离约9.70–32.48m；全部6160N来自不同道路段、距离约88.60–1275.73m；1150I均在同一道路段。主分析每题实际评分图库为140N加1–3P，分别是8题1P、34题2P、2题3P，其余25–27张被忽略；敏感性分析为140N加1–2P。因此当前结果尚不能证明同一街道内精确位置区分能力。82P中43对同月，已有跨月样本，但并非独立设计的跨时间鲁棒性实验。6160N中仅23对直接经人审，其他6137对由规则生成；当前Top5困难N输出用于定位复查对象，不自动转成人工真值。

95.45%的Recall@1意味着只有2题能通过从错到对继续提升该指标。候选干预即使改变判别依据，也可能保持Top1不变，因此不能只看准确率。建议继续沿用margin变化，并同时保存best P、best N各自的相似度与身份；每次干预后在全部固定N中重新求最大值，不锁定基线Top5。若未来要主张细粒度定位，应另建版本化、独立复核的同街道近邻困难题，不把现有I直接重标为N来压低基线。

建议下一步：

1. 同步服务器原始验收资料，并在报告层修正子片区汇总。无需重跑图像预处理、特征提取或已通过的评分。
2. 开始Qwen候选区域的小样本试运行，再覆盖44个query。模型只看单张query；不提供reference、P/N/I、坐标或baseline成绩。先返回可见性、框坐标、重复/越界检查材料。
3. 框审查通过并固定匹配规则后，比较query-only descriptor removal/retention与匹配区域。固定图库、P/N/I、词典和评分器；保留零效应/负效应，不只选择成功例。随后按预定分层做输入级干预。

当前结论限于固定DINOv2+VLAD表示下的地点检索参照。它尚未证明具体候选具有导航地标功能，也没有建立或验证认知地图。
